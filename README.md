## 💡 Sobre

Este repositório reúne o conteúdo do curso, separado por **período** e **disciplina**. O objetivo é:

- Manter um acervo organizado e acessível a toda a turma;
- Facilitar a revisão de provas e conteúdos de semestres anteriores;
- Ajudar calouros e veteranos com material de qualidade;
- Registrar os projetos e códigos desenvolvidos nas disciplinas.

## 🏷️ Convenção de nomes

Para manter tudo padronizado:

- **Pastas:** minúsculas, sem acentos, separadas por hífen
  `estruturas-de-dados`, `banco-de-dados-1`
- **Arquivos de prova:** `tipo-ANO-SEMESTRE.pdf`
  `p1-2025-1.pdf`, `final-2024-2.pdf`
- **Atividades:** `atividade-NN-tema.pdf`
  `atividade-03-recursividade.pdf`
- **Livros:** `autor-titulo.pdf`
  `cormen-algoritmos.pdf`

## 🚀 Como usar

Clone o repositório:

```bash

cd NOME-DO-REPOSITORIO
```

Para baixar apenas uma disciplina, use o botão **Code → Download ZIP** ou navegue pelas pastas direto no GitHub.

## 🤝 Como contribuir

Toda a turma pode contribuir com provas antigas, resumos, listas de exercícios e correções.

**Não usa Git?** Sem problema: abra uma [*issue*](../../issues) descrevendo o material e anexe o arquivo, ou envie para os mantenedores. Eles organizam nas pastas certas.

**Quem usa Git:**

1. Faça um **fork** do repositório;
2. Crie uma branch: `git checkout -b add/prova-calculo-2025-1`;
3. Adicione o material seguindo a [convenção de nomes](#-convenção-de-nomes);
4. Faça o commit: `git commit -m "Adiciona P1 de Cálculo 2025.1"`;
5. Envie: `git push origin add/prova-calculo-2025-1`;
6. Abra um **Pull Request**.

## ⚠️ Aviso importante

- Os materiais são destinados a **fins educacionais e de estudo**.
- Livros e conteúdos protegidos por direitos autorais pertencem aos seus respectivos autores e editoras. Se algum material precisar ser removido, abra uma *issue* ou entre em contato.
- Provas e atividades são compartilhadas apenas como referência de estudo. Respeite as normas de integridade acadêmica da UFAC e **não** utilize este material para plágio.
- **Não envie** dados pessoais de terceiros (notas de colegas, documentos, contatos) nem materiais que o professor tenha pedido para não divulgar.
- Antes de enviar um material, confira se ele ainda não está no repositório.
- O conteúdo pode conter erros; confira sempre com o material oficial e com o professor.
